# ATLAS architecture

Owner: Claude Code. Rules: `.claude/rules/architecture.md`. Current state as of 2026-11-09: only the foundation layers exist (types, schema, migrations, contracts); services, hooks and stores are not implemented yet.

## Layers (dependencies point downward only)

```
app/**             Expo Router routes and layouts (Claude). Thin: read params, call a hook, render a screen.
src/features/**    Screens and feature UI (Codex). Props/hooks only.
src/hooks/**       Adapter hooks (Claude). Services/stores -> UI-friendly models.          [not yet implemented]
src/stores/**      Zustand stores (Claude). UI/session cache; SQLite is the source of truth. [not yet implemented]
src/services/**    Domain services (Claude). contracts.ts + ports.ts exist; implementations come per feature.
src/database/**    Drizzle schema (exists), client and repositories (later). The only code that touches SQLite.
src/types/**       Zod schemas, inferred types, enums, AtlasError, Result, settings parsing (exists).
```

Dependency direction for shared code: `database` imports enums from `types` (never the reverse), so each concept is defined once.

## Key decisions

| Topic | Decision | Reference |
|---|---|---|
| Source of truth | SQLite; every set completion commits immediately; the active session restores from the database | DEC-006, CONTRACTS.md |
| Errors | Services reject with `AtlasError`; no raw SQLite errors in the UI | CONTRACTS.md |
| Determinism | `Clock` and `IdGenerator` ports injected into services; tests use fakes | `src/services/ports.ts` |
| Migrations | Generated by drizzle-kit; applied at startup before any route renders, with foreign keys off around the migration and `foreign_key_check` after | DEC-013, DATABASE.md |
| Testing | Repositories and services run against a real in-memory SQLite built from the shipped migrations | `tests/helpers/testDb.ts` |
| Styling and theme | NativeWind consumes Codex's tokens in `src/theme` (FND-08) | DEC-005 |
| Offline and privacy | No network or analytics code in the app | CLAUDE.md |
